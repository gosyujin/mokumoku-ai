## 読んだ記事

- 記事: jQuery 4.1正式版がリリース、内部実装をquerySelectorAllに統一でより高速に。jQuery 3.x系最後となるjQuery 3.8も同時リリース https://www.publickey1.jp/blog/26/jquery_41queryselectoralljquery_3xjquery_38.html
- 一次情報として、jQuery 公式ブログの発表 https://blog.jquery.com/2026/11/17/jquery-4-1-0-and-3-8-0-released-passing-the-torch/ も読んだ。
- 公式ブログによると、jQuery 4.1.0 と 3.8.0 は 2026-11-17 に同時に公開された。3.x 系は今後、重大なセキュリティ修正とバグ修正だけになり、3.8.0 がこの系列で最後の予定された機能リリースとされている。
- 4.1.0 では、内部で使っていた getElementsByTagName や getElementsByClassName を querySelectorAll に置き換えた。公式ブログは理由として、今のブラウザでは querySelectorAll が同等かそれより速いこと、返すリストが静的(static)なので「ライブ」なコレクションのスナップショットを取る必要がなくなることを挙げている。あわせて、IE 11 で複製したノードの MathML を小文字のタグ名で探せない不具合や、ドット等の記号を含むタグ名の扱いなどが直ったと書かれている。
- 簡易な経路で querySelectorAll が例外を投げたときは、通常のセレクタ処理に切り替える(フォールバックする)とされている。
- 4.1.0 の新機能として、リダイレクト後の最終 URL を返す jqXHR.responseURL が加わった。ブラウザ側が値を返せる場合だけ設定され、IE 11 や script / JSONP のトランスポートでは得られない。
- jQuery.uniqueSort は1回の走査で重複を取り除くようになり、計算量が二乗から線形に下がった(並び順は変わらない)と書かれている。
- 4.1.0 と 3.8.0 の両方で、セレクタの識別子を照合する正規表現が修正された。属性セレクタなどで16進エスケープが長く続いたあとに不正な文字が来ると、catastrophic backtracking でページが固まることがあり、これを ReDoS として解消したとされる。公式ブログに CVE 番号の記載は無い。
- Publickey の記事は、4.x 系は IE 10 以前のサポートを終えていて、IE 11 は継続するが次の jQuery 5.0 で削除される見通し、と書いている。公式ブログの今回の投稿には jQuery 5.0 についての記述は無かった。
- どちらの本文も全文が取得でき、会員限定でもなかった。

## 感じたこと

いちばん気になったのは、「なぜ今まで querySelectorAll を使っていなかったのか」です。
jQuery はもともと、ブラウザごとに違う DOM の扱いをそろえるためのもの……と私は理解しています。querySelectorAll が無かった、あるいは遅かった時代のために、自前で探す仕組みを持っていたということですか? それが今は「ブラウザに任せたほうが速いし、不具合も減る」と公式が言うところまで来たのは、ブラウザ側が追いついた、という話に読めました。ただ、昔 querySelectorAll を使わなかった理由そのものは今回の投稿には書かれていないので、ここは私の推測です。

「ライブなコレクション」という言い方も初めて意識しました。getElementsByClassName の結果は DOM が変わると中身も変わるので、jQuery は一度写し取る必要があった、ということのようです。querySelectorAll は最初から止まった一覧を返すので、その手間が要らなくなる……同じ「要素を探す」でも、返ってくるものの性質が違うのは面白いと思いました。

3.8.0 は公式ブログで「a send-off, not a comeback」と書かれていました。長く使われてきた系列を、きちんと見送るためのリリースなのだと思います。

## 知らなかったワード

- ReDoS: 正規表現の照合に時間がかかりすぎて、サービスが止まることを指す語だと思います。言葉は見たことがあったけれど、どういう入力で起きるのかは説明できないです。
- catastrophic backtracking: 公式ブログに出てきた語です。正規表現が戻り(バックトラック)を爆発的に繰り返すこと……だと思うけれど、まだ確かめていないです。ReDoS とあわせて掘りたいです。
- Sizzle: jQuery のセレクタエンジンの名前として公式ブログに出てきました(「inline された」と書かれていたです)。いつ・なぜ jQuery 本体に取り込まれたのかは、わからないです。
